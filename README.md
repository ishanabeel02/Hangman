# 🪓 Hangman Game in C++

A classic Hangman game implemented in **C++**, featuring categories like animals, fruits, vegetables, and objects. Includes a colorful console interface and ASCII art-based hangman drawings.

## 🎮 Game Features

- Random word selection from 4 categories: Animals, Fruits, Vegetables, Objects.
- Dynamic ASCII-art-based Hangman drawing.
- Sound and color alerts for incorrect guesses.
- Life system with up to 6 incorrect attempts.
- Encouraging and fun messages for correct and incorrect guesses.

## 🧠 Categories Included

- 🐾 Animals (e.g., tiger, zebra, eagle)
- 🍎 Fruits (e.g., mango, apple, kiwi)
- 🥕 Vegetables (e.g., onion, beet, chili)
- 🪑 Objects (e.g., chair, phone, book)

## 💻 How It Works

1. The program randomly selects a word from a chosen category.
2. The user guesses one letter at a time.
3. Each wrong guess reduces a life and updates the Hangman drawing.
4. The game ends when:
   - All letters are guessed (You Win! 🎉)
   - Lives reach zero (You Lose 💀)
